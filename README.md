# Fishing Game

A terminal-style fishing game for the browser and desktop.

## Play and download

- [Play in your browser](https://lyuwenhan.github.io/fishing-game/)
- [Download the latest release](https://github.com/lyuwenhan/fishing-game/releases/latest)

Fishing Game is available in the browser and on Windows, macOS, and Linux.

## About the game

Start with a simple fishing trip, earn rewards from your catches, and use what
you collect to progress through the game. Visit the shop, try your luck in the
lottery, and take on parkour and adventure challenges as they become available.

The game uses a command-line-inspired interface. Make choices from the terminal,
manage your progress, and return to continue from your saved game.

## Features

- Terminal-style presentation and keyboard-driven interaction
- Fishing and progression systems
- Shop and lottery activities
- Parkour and adventure challenges
- Local save data
- English and Simplified Chinese
- Browser and desktop versions

## Languages

English and Simplified Chinese are included. In the desktop application, use
the **Language** menu to switch languages. Your selection is remembered the next
time the game starts.

## Save data

Game progress is stored locally on your device. Browser and desktop saves remain
on the device and in the application where they were created.
